## Finance：还原模块的相互关系

- **画布**：原稿外层占图宽约 90%，外灰内白，大圆角；上部菜单/品牌/用户/搜索一行，上方灰白问候区约占画布高度 29%。
- **问候区**：日期圆、两行月份、竖分隔线、胶囊任务按钮和日历；右侧两行大标题，第二行浅灰，独立麦克风圆按钮。
- **主体**：约 75:25 主区与右栏。主区上方为窄竖工具条、银行卡、收入/支出和锁定/增长环；下方为约 1:1.73 的年度利润与活动管理。
- **嵌套关系**：银行卡白色内卡压在浅灰费用区上；收入区白色、支出区浅灰；活动管理内部再嵌三张白卡。这些层次通过背景与圆角建立，避免大阴影。
- **图表**：四个底部相切、逐级缩小的利润圆；黑色增长环；30 个状态点；带年份标签的细网格；细线 sparkline；细竖条活动图。
- **微细节**：Visa 字样、带圆底的操作图标、搜索与三枚筛选胶囊、轮播圆点、五个不同弧线的评价按钮。
- **配色转译**：主要 CTA 使用信号红；套叠圆改为透明白玻璃、红色圆与深黑亚克力，避免不透明灰色堆叠；收入、增长环和折线用红色表达数据重点。

## HR：四栏节奏与跨行叠层

- **画布**：原稿外框占图宽约 89%，内部宽松的大标题与超细大数字。原奶油黄渐变改为白色场域中的微弱红色环境反射。
- **导航**：描边品牌胶囊、横向白色胶囊导航、近黑选中项、设置与圆形图标。
- **指标**：左侧 15/15/60/10 四段比例条，第三段斜纹；右侧 78/56/203 三个大数字。
- **主体**：四个近等宽栏，间距约为卡片宽度的 1–2%；大圆角。首行人像、Progress、Time tracker、Onboarding；第二行左设备折叠区，中间两栏日历，右侧任务区跨行。
- **Progress**：6.1h 与小字说明；7 根细柱，周末斜纹柱，柱下圆点与字母，周五顶部胶囊提示。
- **Timer**：细表盘刻度与粗弧线共存，中心两行时间/说明；下方开始、暂停、重置三按钮。
- **任务卡**：白纸层、灰纸层与黑色亚克力卡形成三层错位。每行包含圆底图标、两行文字、圆形复选框；完成项减弱并划线。
- **日历**：月切换胶囊、6 个工作日列、虚线与 4 个时间刻度；第一条会议黑底，第二条白底；重叠成员圆形缩略标识。
- **配色转译**：底层保持白色，卡片使用半透明白与背景模糊；选中柱、录用分段及完成状态用实红强调。人物图从原图裁切，灰度呈现。进度按真实复选状态计算，初值 2/5（40%），不照抄原稿中彼此不一致的 18% 和 2/8。

## TripAI：保留场景与玻璃信息层

- **可见结构**：目的地横幅、右上缩略图、左侧目的地标题与说明、底部磨砂胶囊导航和两个图标；其下是天气、预算竖条、繁忙程度柱图；地图占下半部，带分类工具条、缩放与悬浮地点卡。左侧有助手面板。
- **配色转译**：青色风景转为灰度；黄色助手面板转为白色亚克力；预算/繁忙度的有效数据柱转信号红；地图的路径使用红色细虚线。
- **图像处理**：风车场景从所保存的倾斜静帧做透视校正和裁切，重建天空区域以移除嵌入在图像中的原 UI 文案；风车/缩略图仍源于原图。此图分辨率与可用画面有限，不能等同于原照片素材。
- **限制**：原静帧裁去了左侧部分界面，因此工作区导航与助手输入区是对可见结构的补全；示意地图不是地理导航服务；没有声称完整或逐像素复刻原动画。

## 原主题与技术

主题来源为原仓库 src/theme/crease.css 与 https://bloom-gem-crane-flame.grok.me 。保留白底、深黑亚克力与红色主操作、Outfit/Syne 与红色 --signal；亚克力保持足够黑。三份参考页使用 React、Tailwind CSS v4 及真实 shadcn Button / Dialog / Input（Radix）。所有字体、使用的图像均在本地，运行时无外部字体/图片依赖。

/#original 保留原始主题供比较；新样式限制在参考页类名，不修改旧模板的布局。

## 简化与响应式

保留确实表达信息的图形与层次，去掉额外仪表盘框架、动画库、通用页面配置引擎和未使用的组件。图表直接由 SVG / CSS 表达。只保留必要状态；表单、切换、计时器与复选框具有真实本地行为，不伪装成功的外部交易。

桌面按原稿组合；小屏将原模块重排成单/双列，保留财务活动卡、HR 任务与旅行助手。支持 reduced-motion、键盘焦点、对话框焦点管理和页面跳转链接。

## 材质修正 · 2026-10-22

参考图的灰感应来自玻璃透光、模糊与叠层，不能用大面积不透明灰底模拟。外场保持白色，卡片使用透明度约 40%–74% 的白色渐变、22px backdrop blur、细微内高光与接触阴影；下层轻微红色环境反射可以透过卡片。深色亚克力落到近黑端，保留表面反光而不是整体提亮成炭灰。红色扩展到主行动、选中区域、关键数字和有效数据段，形成清楚的视觉节奏。保留原参考布局与中文交互。

### 冰蓝环境光试版

在三套参考页的画布底层统一加入右上方低饱和冰蓝光和下方更弱的冷色反射，通过现有半透明玻璃透出。冰蓝仅作为环境照明，不改变按钮、文字或图表的白红黑配色；保留局部红色反射形成冷暖层次。

### 文字可读性

页面由展示稿比例调整为可阅读界面：辅助标注不低于 12px，常规导航和正文使用 14px；浅色玻璃上的次级文字统一加深至 #555b63，深色任务与日历卡保留浅色文字。字号增大后允许说明换行，手机日历隐藏装饰性头像，避免挤压事件文字。
