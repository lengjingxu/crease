# CREASE 交互原则

本文件是 CREASE 的交互规范，与 `design.md`（视觉）同级生效。参数提炼自 vibedesign.tips 全站 22 篇交互研究，并已按 CREASE 的材质与令牌转译；每条原则都标注了代码落点。可操作的完整演示在组件库的「交互实验室」页（`src/templates/interaction-lab.tsx`），22 项逐项对应本文件编号。

## 总则

1. **只动 transform 与 opacity。** 需要「变模糊 / 变阴影」的效果用两份预渲染交叉淡化，不动画 blur、width、height、top、margin、box-shadow 本身（阴影靠切换预设值过渡）。
2. **退出恒短于进入。** 小 UI 进入 150–250ms、退出 120–200ms；中型浮层 250–350ms；全屏连续性转场桌面约 300–450ms。
3. **延迟成对出现。** 加载态 300ms 后才显示、显示后至少留 500ms；菜单打开延迟约 220ms、关闭宽限 360ms；空状态淡入 300ms、被内容接替时淡出 180ms。
4. **错峰有上限。** 同批入场按 45ms 阶梯延迟，最多 8 档；位移与角度按 0.7ⁿ 几何衰减。
5. **手势 1:1 跟随，松手把速度喂给弹簧。** 新动作从当前帧打断旧动画；动画永不阻塞输入；Esc、点外、拖出等于取消并原路返回。
6. **效果有配额。** 一屏一张全息卡、一页一种滚动特效、一个产品一种删除特效、同时最多 3 个删除特效、每次等待只出现一种加载态、一个区域只留一个主按钮。
7. **降级是默认档。** `prefers-reduced-motion` 下全部位移 / 缩放 / 弹簧降为约 150ms 纯淡化；`prefers-reduced-transparency` 回退不透明面；焦点守恒（浮层关闭后回到触发元素），触控目标 ≥ 44px，键盘与指针同权。

## 动效令牌

定义在 `src/theme/crease.css` 的 `:root`，并映射为 Tailwind 的 `ease-*` 工具类。禁止裸用默认 `ease`；linear 只给旋转与进度类「运转」动画。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dur-1` | 120ms | 按压、微反馈 |
| `--dur-2` | 180ms | 悬停、颜色与阴影切换 |
| `--dur-3` | 260ms | 小浮层、退出坍缩 |
| `--dur-4` | 420ms | 首次入场、内容展开 |
| `--dur-5` | 640ms | 图表描画上限、长转场 |
| `--ease-enter` | `cubic-bezier(0,0,.58,1)` | 进入 |
| `--ease-settle` | `cubic-bezier(.22,1,.36,1)` | 点击落位、落定 |
| `--ease-exit` | `cubic-bezier(.42,0,1,1)` | 离开 |
| `--ease-move` | `cubic-bezier(.42,0,.58,1)` | 屏内移位 |
| `--ease-continuity` | `cubic-bezier(.32,.72,0,1)` | 共享元素转场 |
| `--ease-overshoot` | `cubic-bezier(.34,1.56,.64,1)` | 仅 ≤64px 的确认类小元素 |

补位 / 落定弹簧签名：`1 − exp(−7t)·cos(6t)`（520ms）；展开：`1 − exp(−8t)·cos(6t)`（580ms）。同心圆角贯穿全部嵌套：`内圆角 = 外圆角 − padding`，下限 4px。

## 22 条原则与落点

1. **按压按钮（001）**：按下四件事同发——下沉 1px、渐变翻转、投影塌到 `0 1px 1px`、顶高光变内阴影；时序 transform 120ms / 阴影 140ms / 颜色 160ms。五层材质（面渐变、边、顶高光、底暗线、双层投影）共用一套结构、长度以 em 随字号等比缩放。落点：`crease.css` 的 `[data-slot="button"]:active` 与 `.crease-pressable`；交互实验室 001 有四变体 × 四档字号的完整拟物对照。
2. **级联菜单（002）**：安全三角 + 三延迟——打开 220ms、关闭 360ms、指针在三角内停留上限 1.2s（每 80ms 复查）。落点：交互实验室 002；业务菜单复用同一时序。
3. **ASCII 与抖动（003）**：有序抖动用 Bayer 4×4 阈值 `(m+0.5)/16` 并按强度做多级量化（8→2 级）；ASCII 以亮度映射字符密度并走色调曲线（black 0.22s、white 1−0.08s）。两者共用四站调色板，效果太抢眼先升竖向遮罩。只用于氛围与品牌图形，不用于承载信息的图片。落点：交互实验室 003（真实图源 + 五套调色板）。
4. **嵌套与连续圆角（004）**：`内圆角 = 外圆角 − padding`；大圆角容器渐进增强 `corner-shape: superellipse(1.25)`，不支持时回退普通圆角。落点：全主题约定，交互实验室 004 对照演示。
5. **拖拽排序（005）**：让位走涟漪律——邻项位移 `A × 0.7ⁿ`（条目 A≈8–10px）、延迟 `24ms × n`；被拖项竖列缩到约 90%。落点：交互实验室 005；列表排序类组件按此实现。
6. **书本卡片（006）**：多层展开角度 `42° × 0.7ⁿ`、延迟 `28ms × n`，关闭反序；阴影用两对预模糊形状交叉淡化，绝不动画 blur。落点：交互实验室 006。
7. **中英混排（007）**：标题 `text-wrap: balance`、数字一律 `tabular-nums`、截断容器补 `min-width: 0`；中文标题按词界断行（`word-break: keep-all` 思路），不逐字断。落点：全主题排版约定，交互实验室 007 有开 / 关对照。
8. **Wiki 布局（008）**：目录当前节 = 视口顶部向下 20% 参考线之上的最后一个标题；目录与正文各自滚动，列表边缘上下渐隐遮罩约 40 / 56px。落点：交互实验室 008；长文档页按此做 scrollspy。
9. **浮层选择（009）**：能撤销就不确认（直接执行 + Undo）；Tooltip 首个悬停延迟后出现（原文约 500ms，本仓库基线 350ms，以 design.md 为准）、相邻立即；Popover 装短内容、Dialog 装决策、Drawer 永不用来确认。落点：`kit/feedback.tsx` 的 ConfirmDialog 只用于不可撤销动作；交互实验室 009。
10. **液态玻璃（010）**：模糊只用 `blur(2px)` + `saturate(180%) brightness(1.06)`，颜色来自背后内容；折射只发生在边缘带（宽 `min(44px, 短边/3.5)`）。纯色背景、小元素、失败态不用玻璃。落点：`crease-glass` 的使用边界；交互实验室 010。
11. **缓动曲线（011）**：按上表角色选曲线，不按手感随手填；overshoot 只给 ≤64px 的确认类元素，spring 时长取普通档约 1.5 倍。落点：令牌表；交互实验室 011 可逐个触发对照。
12. **消息气泡（012）**：入场弹簧按材质取 response 0.34–0.52s / damping 0.74–0.92；删除补位由最近者先动（约 60ms）、其上每条晚 50–80ms，落定保留 20–45% 速度的轻微反弹；同组气泡贴合边圆角收到 10px。落点：`kit/chat-panel.tsx` 后续改造依据；交互实验室 012。
13. **冲击波光晕（013）**：半径 1000ms 内按 `650 + 800×(1−2^(−9t))/(1−2^(−9))` 增长，强度 `min(1, t/0.03)×(1−t^2.2)`；只给主行动的成功反馈，不给失败与普通点击。落点：交互实验室 013。
14. **删除卡片（014）**：默认式 = 240ms 淡出 + 缩 4% + 高度坍缩；特效式（燃烧 / 烟羽 / 碎块 / 剥离）只选一种作为产品签名——燃烧最戏剧、烟羽最温和、碎块先过 70ms 命中帧（胀 4% + 闪白 55%）、剥离适合贴纸类；补位弹簧在特效进行到约一半时启动；同时最多 3 个，超了回退默认式。数据在点击时即提交，特效只是离开的画面。落点：`crease.css` 的 `.crease-exit`；`templates/files.tsx` 已接入默认式；交互实验室 014 四式对照。
15. **界面连续性（015）**：状态变化时被操作的元素本身移动 / 生长到新状态（FLIP / 共享元素），新内容在移动 45–55% 后淡入、旧内容在前 25–35% 淡出，返回逆放原路；曲线用 `--ease-continuity`。紧凑条展开时背景缩 0.94 并压暗 30%。落点：交互实验室 015；卡片展开类交互按此实现。
16. **Toast 与通知（016）**：状态型反馈走 Toast——顶部居中、高 40px、圆角 16px（内图标 24px / 圆角 8px，同心），进入 500ms、退出 220ms，停留 3–5s，一次只一条；需要留存或带动作的走通知卡——宽 344px、右上堆叠（露出 12px、缩放 95% / 90%），新卡 560ms 落入，动作型停留 ≥5s。落点：`kit/toast.tsx` 的 `ToastProvider` / `useToast`（`toast()` 与 `notify()` 双通道）。
17. **加载状态（017）**：铁律——等待 <300ms 不显示任何加载态、显示后至少留 500ms、一次等待只一种态；spinner 最少转整圈 640ms；骨架亮带 1.2s 全列同步扫过，真实行以 200ms 淡入、40ms 间隔逐行接替；长任务用进度卡，不用无限转圈。落点：`kit/feedback.tsx` 的 StatePanel（骨架已用 `.crease-shimmer` 同步扫光）；交互实验室 017 演示延迟与最短停留的成对规则。
18. **全息卡片（018）**：倾斜 ±12°，指针跟随用近临界阻尼平滑（无过冲），光点跟随同理；翻面弹簧约 0.8s，厚度 10px（正反各 5px + 轮廓边）。一屏最多一张。落点：交互实验室 018。
19. **滚动驱动卡片（019）**：一切属性是进度 `p = clamp((scrollY − start) / distance, 0, 1)` 的函数，无吸附；堆叠卡 `scale = 1 − k×0.05`、变暗 `k×0.12`、边条 16px；飞牌逐张以抛物线左右交替飞出；钉住画廊纵滚 1:1 变横移；图片展开用 `clip-path: inset()` 从图框开到满幅；封面流 `rotateY = clamp(d, −1, 1) × (−30°)`、透视 1400px。容器高 <560px 时全部退回普通布局。一页最多用一种。落点：交互实验室 019 五式齐全。
20. **选择控件（020）**：2–5 个短选项单选 → 分段控件；≥6 个 → Select；上百个 → 带搜索的 Select；开 / 关永不用两个 radio（用 Switch）；菜单装动作、Select 装值。落点：全主题表单约定；交互实验室 020 三组对照。
21. **环形卡片（021）**：卡片按弧长等距排布（`R = N × step / 2π`，曲率 `c = bend / R` 统一内视 / 外视定位）；视角切换 1100ms（`cubic-bezier(.65,0,.35,1)`），切外视时全体按距中心滞后逐张翻面（1800ms 波）；白底不用阴影做深度，改用大小、模糊、淡出分层；卡面四色渐变流动循环约 17s。拖动 1:1 跟随、松手按速度滑行吸附。落点：交互实验室 021（11 张卡，内视透视 860 / 外视 1500）。
22. **空状态（022）**：先分种类（首次使用 / 无结果 / 全部处理完 / 加载失败 / 无权限）再按空间定尺寸——Page（整组中心在容器高度 40% 处，可带主按钮）/ Card（40×40 tile + 22px 图标 + ghost 按钮）/ Row（一行灰字嵌回列表）/ Menu（菜单内一行灰字）；无结果保留搜索词并给一个修法；失败只倒在失败的那一块、错误翻译成人话；无权限说清归谁与怎么进；「全部处理完」不带按钮且插图不用主题色；空状态淡入 300ms + 升 6px。落点：`kit/feedback.tsx` 的 StatePanel 尺寸约定；交互实验室 022 五种 × 四级对照。

## 与视觉规范的衔接

- 光源方向与视觉一致：全部材质顶光、底影；阴影色向环境色微偏的近中性灰，不用纯黑与饱和色。
- 白底忌脏：深度靠大小、模糊、淡出与玻璃层次，不靠重阴影。
- 动效不改变 `design.md` 的任何视觉结论；新增令牌只进 `crease.css`，新业务页面从组件库模板起步时，交互默认继承本文件。
